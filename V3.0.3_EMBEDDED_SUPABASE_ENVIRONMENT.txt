This build includes a root .env file so Bolt/Vite can connect to Supabase without a separate Bolt secrets screen.

Configured values:
VITE_SUPABASE_URL=https://ixqprtabkyurqlqskjxi.supabase.co
VITE_SUPABASE_ANON_KEY=<Supabase anon client key>

Important:
- The URL intentionally uses the project base URL only.
- Do not append /rest/v1/ because supabase-js adds API paths itself.
- Never place the Supabase service-role key in this client application.
- Netlify environment variables may remain configured; they override matching build-time values.
