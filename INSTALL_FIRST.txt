INSTALL IN THIS ORDER

1. Supabase SQL Editor
   Run the complete file:
   supabase/migrations/054_transaction_follow_up_email_engine.sql

2. Supabase Edge Functions
   Deploy:
   supabase/functions/send-transaction-followups/index.ts

   The function uses the same existing secrets as the working email system:
   RESEND_API_KEY
   OUTREACH_FROM_EMAIL
   OUTREACH_FROM_NAME (optional)
   SUPABASE_URL
   SUPABASE_ANON_KEY
   SUPABASE_SERVICE_ROLE_KEY

3. GitHub / Bolt
   Replace only:
   src/store/TransactionAutomationStore.tsx
   src/pages/owner/TransactionAutomationCommand.tsx

4. Test
   Open Owner > Automation.
   Click "Plan & send follow-ups".
   The engine will create deduplicated reminders and send all due messages.
