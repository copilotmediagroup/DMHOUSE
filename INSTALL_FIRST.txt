DMH SALES OS v4.0.0 — INSTALL FIRST

This is a consolidated production candidate, not a single SQL patch.

1. BACK UP
- Download the current GitHub repository ZIP.
- Create a Supabase database backup.

2. GITHUB
- Upload the CONTENTS of this package to the current repository.
- Preserve the active Supabase configuration in src/lib/supabase.ts.

3. DATABASE
- Open supabase/migrations.
- Apply only migrations not already present in the target database.
- The newly consolidated sequence includes 056 through 062.
- Do not rerun migrations blindly on production.

4. EDGE FUNCTIONS
- Deploy/update functions under supabase/functions.
- view-masked-portfolio is supplied as VIEW_MASKED_PORTFOLIO.txt so it can be copied into the Supabase editor without file-association problems.

5. BUILD
npm install
npm run build

6. VERIFY
Complete PRODUCTION_QA_CHECKLIST.txt and SECURITY_VERIFICATION.txt before declaring production release.
