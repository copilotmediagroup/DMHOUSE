DMH SALES OS — DIGITAL CLOSING ENGINE v3.0.7

INSTALL ORDER

1. In Supabase SQL Editor, run the complete file:
   supabase/migrations/053_digital_closing_engine.sql

2. Replace these two application files:
   src/pages/owner/OwnerBuyerDealRoom.tsx
   src/pages/buyer/BuyerDealRoom.tsx

3. Do not replace or edit:
   package.json
   package-lock.json
   .env
   src/lib/supabase.ts
   invitation Edge Functions

4. Refresh the application and test with an active deal room.

OWNER TEST
- Approve agreement
- Enter payment method, amount and reference
- Verify payment
- Ensure a final_portfolio document exists
- Release final files
- Close deal

BUYER TEST
- Open Deal Room
- Confirm payment status appears
- Download the released final portfolio file
- Confirm the download appears in Owner download history
